## 人机中国象棋对战 (谭子沐象棋) — 构建完成

在 `/Users/kenttt/Documents/谭子沐象棋/` 交付了一个完整的人机中国象棋 web 应用。

**关键决策**
- 需求：人机对战 + 每步反应 ≤3秒 + 可用 GitHub 开源模型。
- 评估了 Pikafish (official-pikafish/Pikafish) 与 ElephantEye (xqbase/eleeye)。但本环境代理对单条下载连接限 ~120s，Pikafish 的 NNUE 权重 49MB、ElephantEye 源码 >上限，无法下载/编译原生二进制。
- 改为内置**自研 JS 棋力引擎**：alpha-beta + 迭代加深 + 硬时间预算 + 静态搜索 + 置换表 + 中文记谱。默认最高难度预算 1800ms（≈1900ms 实际），稳定 < 3s。
- 服务端 `server.js` 保留可选原生引擎接入路径（ENGINE_PATH + ?useEngine=1），供联网后升级到 Pikafish。

**结构**：engine/xiangqi.js(规则), engine/ai.js(搜索), public/(index.html/style.css/app.js/worker.js), server.js(零依赖静态服务器), test.js(单元测试), README.md。

**验证**：自对弈 60 步无非法着法/无崩溃；计时 ≤3s。`node test.js` 全绿。（注：红方开局合法着法修正后实为 44，见下。）

**运行**：`node server.js` → http://localhost:3000

## 规则 Bug 修复 + 吃子特效
- **Bug**：`addMove`（engine/xiangqi.js）只判断“是否为敌子”，未排除“走到己方棋子”，导致将/士/象/马/兵可“吃”自己人（如黑将吃己方士）。已修复：目标格为同色棋子时直接跳过。修正后红方开局合法着法由 46 修正为 **44**（标准值）。
- **吃子特效**：落子若为吃子，目标格播放红色扩散圆环 + “吃”字（约 0.6s）。已同步到单机版(app_standalone.js)与服务器版(public/app.js)。
- 回归：`node test.js` 全绿；引擎修改后自对弈 60 步无非法着法。
- 规则教训：象棋走子生成里 non-sliding 棋子的 addMove 必须排除“移动到己方棋子”，否则会把“走到己方格”误当普通走子。
