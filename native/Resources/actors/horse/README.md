# 马 · 序列帧素材规范

把奔跑马的序列帧 PNG 直接放进这个目录，重新运行 `build_app.sh` 即可自动打包并启用。
**目录为空时**，App 会自动退回程序化绘制的马剪影——不会报错、不会黑屏。

## 命名

固定前缀 `run_` + 两位序号，程序按**文件名排序**播放，所以帧序完全由文件名决定：

```
run_00.png  run_01.png  run_02.png  ...  run_11.png
```

- 序号从 00 开始，连续不跳号最好；跳号也能跑，只是播放时会按字典序衔接。
- 建议 8 ~ 16 帧。播放帧率固定 **16 fps**（一整趟跑过约 3.6 秒）。

## 画布

| 项 | 要求 | 原因 |
|---|---|---|
| 尺寸 | 512×512 或 1024×1024，**所有帧必须一致** | 不一致会导致马身抖动、忽大忽小 |
| 格式 | PNG，**透明背景**（RGBA） | 需要透出后面的棋盘 |
| 朝向 | 马头朝**右** | 程序需要反向跑时自动水平镜像 |
| 脚底对齐 | 四蹄最低点贴在画布**底边**，马身在水平方向居中 | 程序以画布底边作为"蹄底"、以中线对齐落点 |

## 建议

- 不要带外部投影或水印——阴影由 App 自己画（蹄后扬尘也是程序生成的）。
- 相邻帧的**躯干高度尽量稳定**，只有四肢摆动，观感最自然。
- 若素材带白色描边/残留背景，可先用项目里的 `tools/` 脚本做一轮抠底处理。

## 换成其它动物

复制一份目录改名即可，例如 `assets/actors/tiger/run_00.png`。
运行时改一行 `BoardView.runHorse()` 里的 `ActorAssets.load("horse")` 参数，
同时把 `Actor(name:)` 的名字一起改掉。
